The listener selector requires the observed interface layout: `lo` with the two
standard loopback addresses, and `railnet0` with exactly one RFC1918 IPv4, one

listener and refuses missing, extra, public, mapped, noncanonical or ambiguous
addresses/interfaces. A topology change therefore stops startup pending review.

Stop and remove the previous phase container before starting the next one on the same volume, and verify that no other container/service uses that volume. The fixed state marker and exclusive lock reject replay and incomplete phases. They do not replace provider-level single-volume ownership. On success each phase holds inertly with no PostgreSQL process or listener, avoiding automatic restart/re-enrollment. 1. Run `init` as root with **no provisioning variable or stdin secret**, only on the approved fresh volume. The root must be UID/GID 0 and mode 0700 or 0755. Its only permitted existing entry is an empty `lost+found` directory, UID/GID 0 and exactly mode 0700, opened without following symlinks and checked before any writes. The helper never deletes, chmods or chowns that entry. It creates private application directories, clears supplementary groups, drops permanently to UID/GID 999, runs fixed `initdb` with peer-only local authentication and rejected host authentication, and records `initialized`. Every other existing or partial entry is refused. Root is needed only to verify the fresh layout and set application volume ownership; minimize its capabilities/duration. The Node process and children receive fixed cleared environments.
2. Run `configure` as UID/GID 999 with the exact bounded JSON envelope: `{version:1,host,caCertificate,serverCertificate,serverKey,runtimePassword,migrationPassword}`. The helper validates the single CA, current leaf certificate, exact DNS SAN, RSA key match and server-auth purpose before writing private files. Standard Drizzle needs the owner's temporary CREATE on this database; that also permits schemas, publications and trusted extensions until revoked, but is not global CREATEDB and never belongs to the runtime role.
